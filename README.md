# Formula 1® Race Centre - Live Streaming Hub (2026 Season)

A real-time Formula 1 streaming and live broadcast hub featuring live video player (HLS / M3U8), multi-channel selection, schedule integration, and a mobile-optimized responsive UI.

## Features
- **Live Stream Relay**: HLS.js streaming engine with proxy support for unblocked feeds
- **Official Broadcast Channels**: Sky Sports F1, F1 TV Pro, 50 FPS feeds, and direct master M3U8 streams
- **Race Hub & 2026 Calendar**: Integrated countdown and full 2026 season race calendar
- **Responsive Mobile Layout**: Optimized edge-to-edge layout for smartphones, tablets, and desktop screens

## Quick Start

### 1. Install Dependencies
`ash
pip install -r requirements.txt
`

### 2. Run Application
`ash
python app.py
`

### 3. Open in Browser
Navigate to:
- Local: http://localhost:5005
- Network: http://<your-ip>:5005
